# GameDevUsageBar 0.9.5

Switch a saved CLI account directly from the provider popup. The new **Switch account** button sits before Refresh and Settings. For Codex and Claude, choosing an account restores its encrypted saved auth through the existing guarded switcher, verifies the written identity, and then updates the displayed account. The header dropdown continues to change the displayed account only; API provider buttons also select display accounts.

- Keep the displayed saved account selectable because the CLI may currently use a different login.
- Show switch progress and actionable results in the card, with English and Chinese labels and the existing dark menu style.
- Reject read-only settings before touching CLI auth or encrypted saved credentials.
- Add isolated WPF integration checks for menu identity, event routing, layout, synthetic auth replacement and rejected writes; include them in local checks and Windows CI.

Close CLI sessions before switching. Existing desktop sessions are unaffected. The app does not start a CLI, redeem tickets or automatically replay an unresolved auth write. Windows x64 packages remain self-contained and unsigned.
