# 0.9.7 — isolated Claude authorization browser

This update is local and has not been published on GitHub.

Each attended Claude authorization now starts from a newly created Firefox
profile and a separate instance. Only reviewed proxy/privacy preferences and
an ownership record initialize it; cookies, history, cache, saved passwords,
extensions and session state from other profiles are not imported. Existing
personal browser profiles and saved CLI accounts are retained.

The maintained Bridge continues to enforce its reviewed Firefox executable,
proxy and application network guards. Browser launch is attempted once; an
uncertain outcome is not retried or erased. Authorization still requires the
user to select the intended account. Account display names do not establish
the identity of the subscription being authorized.

Validation distinguishes fresh profile initialization and offline launch
contract tests from an actual attended account authorization.
