# GameDevUsageBar v0.9.1

Released October 5, 2026.

A Windows usage bar for AI subscriptions, API credits, and account balances—with a notification-area menu, a compact desktop strip, and a customizable overview.

**Windows 10/11 x64 · English / Simplified Chinese · Preview**

## Downloads

| Asset | Description |
| --- | --- |
| `GameDevUsageBar-0.9.1-win-x64-setup.exe` | Current-user Windows installer |
| `GameDevUsageBar-0.9.1-win-x64.zip` | Self-contained portable folder |
| `SHA256SUMS.txt` | SHA256 hashes of both assets |

No separate .NET, Node.js, Git, or SDK installation is required. Setup offers logon startup and an optional desktop shortcut. The installer UI supports English and Simplified Chinese.

Downloads are unsigned. Check their hashes and keep security software enabled; hashes are integrity evidence, not an antivirus certification.

## In this release

- **One-row desktop bar:** small provider icons, remaining quotas/credits/currency balances, a proper pin control, position lock, background-transparency slider, and download/upload MB/s.
- **Customizable overview:** choose any two services for the featured modules; inspect the remaining services in compact rows with expandable details.
- **Multiple accounts:** independent credentials, endpoints, usage, freshness, and retry state; quick display selection from service titles or the tray.
- **Explicit Codex/Claude CLI switching:** Windows-user encrypted saved logins and recovery copies; verified auth-file replacement with native directory overrides respected. Existing desktop sessions are left alone.
- **Current Claude OAuth renewal:** the explicitly connected local login renews before access-token expiry while the app is running. Native locks, atomic publication, and saved confirmed responses protect rotation. Saved snapshots and manual tokens are not automatically renewed; unknown outcomes are not replayed automatically.
- **Portable network settings:** provider traffic uses .NET's default proxy selection rather than a fixed private-router address.
- **Useful reset details:** five-hour and weekly windows remain separate; countdowns match the cycle, and reported reset-ticket count/expiry share one row.
- **Nine provider adapters:** Claude, Codex, Tripo, GRSAI, DeepSeek, ElevenLabs, OpenRouter, Gemini CLI, and Gemini AI Studio. Tripo and GRSAI include explicit Global/China choices.
- **Read-only local API:** selected-account and all-account snapshots, per-provider/per-account routes, network speed, and health at `127.0.0.1:17864`. GETs expose no credentials and do not trigger refreshes or paid calls.
- **English and Simplified Chinese:** immediate switching across application surfaces, with custom labels preserved.

## Upgrade and data

Exit the app from its tray menu before setup replaces the installed version. Setup refuses replacement while the app is running; it does not forcibly terminate it.

Settings and encrypted user data remain in `%LOCALAPPDATA%\GameDevBar`. Installation/removal do not replace native CLI logins. Saving multiple/captured accounts uses schema 4; use v0.9.0 or later after that save.

The installer is Windows x64 only. There is no native macOS, Linux, or ARM64 package and no automatic update service.

## Validation and limits

The release source passed **152 behavior checks**, **22 WPF/Win32 integration checks**, the multiple-account UI suite, **6 native-account host checks**, overview-layout checks, and compact/strip/transparency suites. Test credentials and vendor transports are isolated fixtures; screenshots use synthetic sample data.

The real isolated installer passed **62 checks**, including English installation, Chinese reinstallation, payload hashes, shortcuts, startup selection, running-app refusal, uninstall and preservation of seeded user data. It did not launch the normal app against a live profile. The installer and portable archive include third-party licenses and file checksums; release assets are covered by `SHA256SUMS.txt` and `package-manifest.json`.

This does not promise live access for every vendor account. Provider permissions and private subscription endpoints may change. The app displays reported fields rather than inferring fixed limits from Pro/Plus. Optional ticket inventory appears only when returned; live Claude ticket retrieval is not guaranteed.

Tripo credits are API credits, not Studio credits. Gemini AI Studio shows completed Google Cloud project requests over 24 hours, **not remaining quota or balance**, and requires Monitoring OAuth permission. OpenRouter's credits endpoint may require a management key. Missing values remain unknown, and stale/cached data is not treated as a fresh allocation.
