# GameDevUsageBar 0.9.4

Opening a provider popup no longer briefly moves the visible window to the top-left of the monitor. The popup now calculates its anchored position without a visible staging move, and queued content updates use the latest anchor when the popup is reopened.

- Coalesce popup layout updates and refit after DPI changes.
- Add a WPF/Win32 regression that records visible window position events across opening, reopening, content changes and the available monitors. Include it in local UI checks and Windows CI.
- Keep the existing installation directory, autostart configuration and saved account data during an upgrade.

This is a popup positioning fix. Existing provider integrations and account switching are unchanged. Windows x64 packages are self-contained and unsigned.
